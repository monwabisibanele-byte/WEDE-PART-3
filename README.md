# Soweto Fresh Bakery — Part 3 website

A student website project demonstrating JavaScript functionality, basic SEO, form validation and responsive design.

## Included files
- `index.html` — main website page and SEO metadata
- `style.css` — layout, styling and mobile/tablet breakpoints
- `script.js` — navigation toggle, search/filter, gallery lightbox and client-side form validation

## Features
- Responsive layout for desktop, tablet and mobile
- Collapsible navigation on smaller screens
- Menu search and category filters
- Image gallery with lightbox and Escape-to-close
- Embedded map centred on Soweto
- Required-field, email and minimum-length form validation
- SEO title, description, keywords and Open Graph metadata
- Accessible labels, alt text and keyboard-friendly controls

## How to run
Open `index.html` in a browser. An internet connection is needed for the external image URLs, Google Fonts and embedded map.

## Before submitting
- Replace the example contact email and telephone number with the details required by your scenario.
- Confirm the products, prices, images and address match your Part 2 business brief.
- Test the layout at different screen sizes using Chrome DevTools (Ctrl + Shift + I, then Ctrl + Shift + M).
- The contact form is a front-end demo only; it does not send messages to an email inbox.
- External images are loaded from Unsplash and may require internet access.
